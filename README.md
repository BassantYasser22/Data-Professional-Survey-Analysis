# Data Professional Survey Analysis | Power BI

## Project Overview
This project analyzes survey data collected from data professionals to explore their career paths, salaries, programming language preferences, and job satisfaction using Microsoft Power BI.

## Dataset Description
The dataset contains survey responses from data professionals, including information about their professional roles, career transitions, salaries, industries, technical preferences, and workplace satisfaction.

The dataset includes attributes such as:
- **Professional Information:** Current job title, industry, and career transition into data.
- **Salary Information:** Current yearly salary ranges in USD.
- **Technical Preferences:** Favorite programming languages.
- **Job Satisfaction:** Satisfaction with salary, work-life balance, coworkers, management, career growth, and learning opportunities.
- **Career Challenges:** Perceived difficulty of entering the data field and priorities when looking for a new job.
- **Demographic Information:** Age, gender, country, and education level.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- Data Cleaning & Transformation
- Data Visualization

## Data Preparation
Power Query was used to prepare the dataset for analysis, including removing unnecessary columns, transforming columns, and preparing the data for visualization.

## Dashboard Insights
The dashboard highlights:
- Distribution of survey respondents by country.
- Average salary across different data-related job titles.
- Favorite programming languages among respondents.
- Perceived difficulty of entering the data industry.
- Average satisfaction with salary and work-life balance.
- Total survey responses and average respondent age.
